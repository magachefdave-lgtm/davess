# WLR OnAir v3.18.41

## 전체 세부 사용성 검수 반영

1. 연결 설정을 같은 창에서 여러 번 바꿀 때, 성공한 저장값을 기준으로 다음 변경을 판정합니다. 원래 값으로 되돌리는 저장도 반영하고, 저장 대기 중 새로 입력한 값은 보존합니다. 중복 저장은 차단합니다.
2. 기존 모달도 열 때 키보드 초점이 창 안으로 들어가고 Tab·Shift+Tab은 최상단 창 안에서 순환합니다. 창 뒤의 버튼은 작동하지 않으며 닫은 뒤 호출 위치로 돌아갑니다. 펼침 메뉴에서 연 경우 메뉴 버튼으로 돌아갑니다.
3. 승인 목록에서 신규·변경·취소의 시작일·종료일, 변경 전 날짜도 검색할 수 있습니다.
4. 신청 권한 복구창의 Escape는 복구창만 닫고 뒤의 내 신청 내역은 유지합니다.
5. 복구 상태 갱신과 관리자 대상 선택 시 현재 입력·초점·스크롤과 체크 상태를 유지합니다. 과거 요청 응답이 새 화면을 덮어쓰지 않습니다.
6. 사원 추가 중 암호를 취소하거나 저장하지 못하면 이름·성별이 남습니다. 성공했을 때만 등록한 입력을 비웁니다.
7. 복구 조회·미리보기 재시도가 성공하면 이전 오류를 지웁니다.
8. 새 사원 이름은 최대 4자로 입력·검증합니다. 기존 긴 이름은 일정·신청 연결이 끊기지 않도록 그대로 보존하며 백업 복원도 지원합니다. 4자 이름으로 금일 당직자 화면을 1920×1080, 1366×768, 1024×768에서 다시 검수했고 옆 칸 겹침이 없었습니다. 메인 화면의 카드 배치는 유지합니다.
9. 장기 부재·파견 목록은 이름·기간 한 줄을 유지하고, 긴 이름만 말줄임하여 끝 요일까지 보입니다. 전체 이름과 기간은 기존 상세 안내로 확인할 수 있습니다.

## 세부 회귀 보완

- 같은 부모창을 갱신해도 위의 확인창·암호창을 가리지 않습니다.
- 달력에서 날짜를 선택 중일 때 Escape는 선택 취소를 먼저 처리합니다.
- 한글 이름 조합 중 Enter로 사원이 미리 등록되지 않습니다.
- 숫자·객체 등 잘못된 이름 자료는 저장 전에 거절하여 4자 제한을 우회할 수 없고 전체 저장을 부분 반영하지 않습니다.

변경사항·검수기준·구현 계획과 결과는 변경이력 폴더에 모았습니다. 배포관리.cmd와 버전올리기.cmd를 소스 ZIP에 포함합니다.
