## 모달 문제의 원인

부재 관리창이 화면 맨 앞으로 이동한 뒤 관리자 암호창은 처음 생성된 DOM 위치에 남아, 같은 z-index에서 뒤에 그려졌습니다. Escape 처리 순서도 부재 관리창을 먼저 선택했지만 저장 대기 잠금 때문에 닫히지 않았습니다. 기존 공통 모달 raise 기능으로 보이는 순서와 닫기 순서를 함께 맞췄습니다. 등록 후 당직 공백 안내창도 같은 방식으로 처리했습니다.

## 검증 범위

운영 DB 대신 격리된 합성 자료로 검사했습니다. Python 테스트 생략 12건은 Windows cmd.exe 전용 8건, 이전 Python 3.13 marshal 비교 1건, 이전 실행 소스가 필요한 POSIX 전환 픽스처 3건입니다. 4개 경고는 기존 라이브러리 폐기 예정 API·중복 OpenAPI ID·공격 ZIP 시험의 중복 이름 경고입니다.

Windows 실행파일은 별도 GitHub Actions에서 빌드와 EXE 자체점검 후 게시합니다. 실제 Windows 직원 PC의 공유폴더 권한·트레이 상호작용·DPAPI·프로그램 업데이트 재시작은 해당 PC에서 확인하는 항목입니다. 요약 페이지의 빌드 링크와 결과 파일의 BUILD_MANIFEST.json/Admin_SELFTEST.json/Viewer_SELFTEST.json에서 실행 근거를 확인할 수 있습니다.
