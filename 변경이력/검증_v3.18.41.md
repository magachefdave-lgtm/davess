## 생략·제한

12건 생략은 Windows cmd.exe 전용 8건, 과거 Python 3.13 marshal 비교 1건, 이전 소스가 필요한 POSIX 전환 3건입니다. 기존 경고 4개는 라이브러리 폐기 예정 API, 중복 OpenAPI ID 및 공격 ZIP 시험의 중복 이름 경고입니다.

브라우저와 합성 자료의 검증입니다. 실제 직원 PC의 공유폴더 권한·트레이·DPAPI·확대 배율·프로그램 업데이트 재시작은 해당 PC에서 확인하는 항목입니다. Windows 빌드 및 EXE 자체점검은 별도 GitHub Actions 결과와 BUILD_MANIFEST.json/Admin_SELFTEST.json/Viewer_SELFTEST.json을 기준으로 확인합니다.
