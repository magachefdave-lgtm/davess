# WLR OnAir v3.18.40

## CA 담당자와 사용 연결

- 올해와 내년 담당자를 동시에 지정합니다. 기존 1~2년 임기는 보존하며, 서로 겹치는 임기는 저장하지 않습니다.
- 왼쪽에는 연도별 담당자·임기·상태, 오른쪽에는 선택한 임기의 승인 대기·승인된 PC·이전 기록을 구분합니다.
- 내년 담당자는 PC 사용 연결을 미리 승인받을 수 있습니다. 회식 관리 권한은 한국 시간 기준 임기 시작일부터 유효합니다.
- 올해 담당자와 내년 담당자가 같아도 임기별 PC 연결을 선택할 수 있습니다. 회식 관리의 [CA 사용 연결]에서 확인합니다.
- 임기를 수정하거나 해제해도 다른 임기의 PC 연결은 유지합니다. 다른 관리자가 이미 바꾼 지정 내용을 오래된 입력으로 덮어쓰지 못하게 합니다.
- 같은 해에 담당자가 바뀌는 경우에는 해당 연도의 임기를 선택해 각각 관리할 수 있습니다.
- 1920×1080, 1366×768 브라우저 화면의 기본 배율에서 가로·세로 스크롤 없이 확인하도록 모달 폭과 여백을 조정했습니다. 연결 요청이 많으면 2건씩 페이지를 넘깁니다. 작은 화면이나 확대 배율에서는 내용 접근을 위해 세로 스크롤을 허용합니다.
- 메인 화면 구성은 유지합니다.

## 관리자 휴가·부재 등록 창

관리자 암호가 설정된 상태에서 [새 부재 등록]을 누를 때, 암호 입력창이 부재 관리창 뒤에 가려지고 기존 창도 닫히지 않던 문제를 수정했습니다. 암호 입력창과 당직이 비워진 날짜 안내창을 가장 앞으로 올리고, Escape가 현재 보이는 창부터 닫도록 순서를 맞췄습니다. 암호 입력 취소·오류 후 재입력·등록·나중에 처리·원래 편집창 복귀를 확인했습니다.

## 자료 보호

기존 CA 지정과 승인된 PC는 자동으로 호환됩니다. 전체 자료 복원 시 최신 CA 지정은 유지하고 PC 연결은 무효화하여 다시 승인받도록 합니다. 명단에서 제거된 직원의 연결은 같은 이름을 다시 등록해도 되살아나지 않습니다.

## 빌드와 다운로드

Windows 자동 빌드는 소스 지문과 Admin·Viewer EXE 자체점검 결과를 확인합니다. 실행파일 ZIP에는 배포관리.cmd, 업데이트 패키지와 빌드 검증 기록이 포함됩니다. 실제 운영 공유폴더에는 자동으로 게시하지 않습니다.
