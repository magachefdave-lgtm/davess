# v3.18.42 검증 결과

- Windows Server 2022에서 배포관리와 같은 코드로 실제 폴더 및 ZIP 선택 창을 열었습니다. 두 창이 일반 창보다 위에 표시됐으며, 닫아 취소했을 때 기존 경로가 유지됐습니다.
- 실제 Chromium 1366×768과 1920×1080에서 관리자 암호 입력과 재시도, 성공 표시, 취소 후 초점 복귀, 조회용에서 버튼 숨김과 API 접근 거부를 포함한 19개 검사를 통과했습니다. 테스트용 자료와 별도 실행 환경을 사용했습니다.
- Python 1,362건과 하위 검사 18건, JavaScript 868건이 통과했습니다. Python은 환경 조건에 따라 12건을 건너뛰었고 기존 경고 4건이 발생했습니다.
- 관리자용 및 조회용 EXE 자체점검이 통과했습니다. 공개 Windows ZIP을 모바일 브라우저 식별자로 로그인 없이 전부 내려받아 ZIP 검사와 SHA-256 비교를 마쳤습니다. 이 검사는 직원 PC의 실제 운영 환경과 모바일 앱의 다운로드 동작을 포함하지 않습니다.
