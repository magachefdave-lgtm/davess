# v3.18.44 검증 결과

- 서로 다른 포트에서 관리자용과 조회용을 실행하고 같은 공유 자료와 이름으로 투표했습니다. v3.18.43에서는 열린 목록이 갱신되지 않고 관리자용 응답이 다른 PC에서 제출한 것으로 표시되는 두 증상을 재현했습니다.
- v3.18.44에서 게시된 투표의 자동 표시, 관리자용 응답의 조회용 확인, 조회용에서 수정한 응답의 관리자용 표시를 실제 Chromium으로 확인했습니다. 두 창에서 동시에 편집할 때 먼저 저장한 결과가 보존됐습니다. 별도 직원 PC에서 같은 이름을 선택할 때 개인 응답을 볼 수 없는 것도 확인했습니다.
- v3.18.43에서 만든 두 역할별 응답을 v3.18.44로 업데이트한 뒤 각각 반대쪽에서 확인했습니다. 브라우저 검증은 예시 데이터와 격리된 설치 프로필을 사용했습니다.
- Python 검사 1,365건과 하위 검사 18건, JavaScript 검사 868건이 통과했습니다. 환경 조건에 따라 Python 검사 12건을 건너뛰었습니다.
- Windows 관리자용·조회용 EXE 자체점검이 통과했습니다. 공개 Windows ZIP을 로그인 없이 모바일 브라우저 식별자로 내려받아 SHA-256과 구성 파일을 확인했습니다.
