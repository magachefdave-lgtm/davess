# v3.18.49 회식 투표 집계 권한과 최고 관리자용

- 일반 관리자는 근태와 당직 관리, CA 임명 및 사용 연결 승인, 본인 투표를 계속합니다. CA 지정·승인 화면은 회식 응답 자료를 요청하지 않습니다.
- 후보별 가능·미정·어려움 집계, 응답자 명단과 개인 의견, 회식 운영은 승인된 현직 CA와 전용 인증을 마친 최고 관리자가 이용합니다. 12월·1월 인수인계 CA는 해당 시기의 취합만 읽을 수 있습니다.
- 최고 관리자용을 별도 설치하며, 서버에서 승인한 PC에서 전용 암호로 관리 세션을 엽니다. 세션은 15분 후 만료되며 프로그램 종료, 명시적 잠금, Windows 잠금 시 다시 인증합니다.
- 관리자용·조회용 업데이트는 기존 게시 경로를 이용합니다. 최고 관리자용은 배포관리에서 별도 대상으로 선택합니다.
- 이 권한 구분은 새 버전의 앱과 API에 적용됩니다. 공유 DB 및 전체 백업의 Windows 접근 권한과 보관 방식은 기존 설정을 따릅니다.
