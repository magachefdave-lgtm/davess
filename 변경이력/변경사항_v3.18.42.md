# WLR OnAir v3.18.42

- 배포관리에서 찾아보기를 누르면 Windows 폴더와 파일 선택 창이 브라우저 앞에 표시됩니다. 창을 닫으면 경로를 선택하거나 취소하기 전의 배포관리 화면으로 돌아갑니다.
- 암호가 설정된 관리자 화면에서 상단 **암호 인증**을 누르면 기존 관리자 암호 입력창이 열립니다. 올바른 암호는 서버 확인 후 적용되고, 틀린 암호는 입력창에서 다시 입력할 수 있습니다.
- **암호 인증됨**을 누르면 다시 인증할 수 있습니다. 취소하면 직전 인증 상태로 돌아갑니다.

소스 ZIP에 `배포관리.cmd`, `버전올리기.cmd`와 검증 자료를 포함했습니다.
