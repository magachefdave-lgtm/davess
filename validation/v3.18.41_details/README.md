# v3.18.41 세부 사용성 검증 자료

이 폴더는 격리된 합성 자료로 수행한 실패 재현·수정 후 검증 스크립트, 전체 결과 JSON/로그와 대표 화면을 포함합니다. 소스 ZIP의 크기를 줄이기 위해 같은 화면을 여러 해상도에서 촬영한 이미지와 수정 전 이미지는 배포본에서 선별했습니다. 실행 결과 JSON/로그는 해상도별 전체 결과를 보존하며 스크립트를 실행하면 해당 캡처를 다시 생성합니다.

- modal: 공통 창 순서·초점·키보드·Escape·중첩 확인/암호
- recovery: 복구창 닫기·갱신·스크롤·오류 재시도·권한 연결
- settings-search: 설정 파일 저장, 승인 기간 검색, 장기 부재 기간 표시
- names: 사원4자 제한·입력 유지·세 해상도 당직자 표시

실제 직원 PC/운영 공유폴더를 사용하지 않았습니다. Windows 빌드와 EXE 자체점검 기록은 최종 빌드 결과 폴더에 있습니다. 실제 직원 PC의 DPAPI·트레이·공유폴더 권한·업데이트 재시작은 해당 PC 확인 항목입니다.
